# LABA audio assets

`bazhaju-zdorovya.wav` contains the Ukrainian phrase “Бажаю здоров'я!”. It was
generated at 22,050 Hz mono PCM with Piper `1.7.0` and the
`uk_UA-mykyta-high` voice from `rhasspy/piper-voices` using length scale `0.92`,
sentence silence `0.25`, and volume `0.92`. The source dataset declared by the
model card is licensed under Apache 2.0.
