RTSP перевіряється лише через TCP. Для захищеного перегляду в браузері виберіть інтеграцію go2rtc.

LABA відкриє лише конкретний потік через MSE/HLS/MJPEG. API та конфігурація go2rtc залишаться недоступними користувачеві. У полі секрету зберігається Basic Auth самого шлюзу; облікові дані камери мають залишатися на Raspberry Pi.
